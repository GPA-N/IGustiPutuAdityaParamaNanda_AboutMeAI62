Selected projects

Three backend projects built on Google’s Gemini API, and a set of data and AI notebooks.

  • 2026 · Sanbercode Bootcamp, daily assignments

    AI Engineering Notebooks

    Nine end-to-end Jupyter notebooks that follow one workflow: raw data, a working model or pipeline, then a look at where it breaks.

    They cover data cleaning, regression and ensemble models, a PyTorch classifier, structured extraction with Gemini, semantic search with ChromaDB, and RAG evaluation.

    • scikit-learn
    • PyTorch
    • ChromaDB
    • Gemini API

  • 2026 · Sanbercode Bootcamp, final assignment

    NusantaraCare RAG Service

    A FastAPI service that answers questions about a company’s internal operating procedures using retrieval-augmented generation over a 40-chunk knowledge base.

    Chunks from the retired policy version are tagged inactive and filtered out in ChromaDB. Replies use Gemini structured output with a confidence label, and questions outside the documents are refused.

    • FastAPI
    • ChromaDB
    • Gemini API

  • 2025 · Hacktiv8 Bootcamp, Batch 19

    Gemini Flash Multimodal API

    A REST API in Express.js with five endpoints that accept text, image, document, audio, and video input and pass it to Google’s Gemini 2.5 Flash Lite model.

    Uploads are handled with Multer and base64 encoding. Every endpoint returns errors in one consistent JSON format and reads its settings from the environment.

    • Express.js
    • Multer
    • Gemini API

  • 2025

    Gemini Chatbot AI

    A chat backend in Express.js that uses Google’s Gemini API to generate conversational replies from the message history.

    It enables cross-origin requests with CORS, serves a static frontend next to the API, and reads its API key and port from the environment.

    • Express.js
    • CORS
    • Gemini API
