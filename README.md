## Run locally

After editing `styles.css`, `fluid.js`, or `motion.js`, run `node tools/stamp.mjs` (it versions the asset URLs so browsers never pair
new markup with an old cached file), then the checks below.


Open `index.html` in a browser. To run the content checks: `node tests/check-profile.mjs`.
